# Mercury 行业场景

不同生意用 Mercury 的方式略有不同。下面是几个典型场景——如果你的行业不在其中，描述一下你的客户从哪来、常问什么，我们可以判断是否适合。

## 外贸 / B2B 出口

**痛点**：询盘跨时区涌进来，半夜来的客户第二天才回，热度已凉；业务员大量时间耗在"MOQ 多少""能不能 OEM"这类重复问题上。

**用法**：把产品目录、MOQ、认证、交期、付款方式整理进知识库，机器人 7×24 用客户的语言（英文、西语等）即时回答；聊出预算、采购时间的客户自动标为高意向推给业务员。

**效果**：业务员只跟"值得打电话的人"通话，重复答疑归机器人。

## 跨境电商 / DTC 品牌

**痛点**：物流、尺码、退换货咨询占客服 80% 精力；旺季咨询翻倍，人手跟不上。

**用法**：店铺 FAQ、物流政策、产品详情入库；机器人处理常规咨询，退款投诉类自动转人工；广告投 Telegram 的不同素材用不同深链，后台直接看哪条素材带来真买家。

**效果**：客服人力聚焦售后疑难，广告优化有了"到线索"级别的数据。

## SaaS / 软件工具售前

**痛点**：免费试用用户在 Telegram 群里问完问题就消失，谁在认真评估、谁只是围观，完全分不清。

**用法**：产品文档、价格页、对比 FAQ 入库；机器人答疑的同时提取团队规模、预算、上线时间；安静几天的评估者自动收到一条跟进消息。

**效果**：试用用户被分成"打了分的名单"，销售精力花在真正在选型的人身上。

## 营销代理 / 服务商（白标转售）

**痛点**：手里管着多个客户的 Telegram 渠道，想给客户提供 AI 接待能力，但没有自研团队。

**用法**：每个终端客户部署一个独立实例（独立数据库、客户自己的品牌和机器人），代理商统一采购、分别交付；每个实例的知识库和评分规则按终端客户的业务配置。

**效果**：代理商多了一个可复售的标准化服务项。多实例合作条款请找人工洽谈。

## 教育 / 课程咨询

**痛点**：家长和学员的课程咨询集中在晚间和周末，顾问下班后咨询全部流失。

**用法**：课程大纲、价格、开班时间、师资介绍入库；机器人先接待并识别意向（问到价格和时间的通常是认真想报的），高意向名单第二天一早推给课程顾问。

**效果**：晚间咨询不再流失，顾问上班第一件事是跟进热名单。

## 地产 / 本地高客单服务

**痛点**：展会、广告牌带来的扫码咨询没人接；买家问的户型、价格、位置问题高度重复。

**用法**：楼盘/服务资料入库；线下物料印不同渠道的二维码（展会一个码、门店一个码），机器人即时接待并留资打分，约看请求直接转人工。

**效果**：线下投放第一次有了可度量的线索转化，扫码客户零流失。
