# Mercury 价格与交付（草案——正式报价以沟通确认为准）

> 注：本文档为试点期定价草案，你（运营者）可随时在后台更新此文档调整对外口径。

## 试点方案（当前阶段，限量 2 个名额）

**一次性 $500–1000（按需求复杂度报价）**，包含：

- 系统独立部署（专属实例、独立数据库）；
- Telegram 机器人接入与品牌配置（欢迎语、回复语气按你的品牌调）；
- 知识库整理与导入（协助把你的产品资料整理成机器人可用的知识库）；
- 线索评分规则按你的业务定制（什么样的客户算高意向，由你定义）；
- Google Sheets 线索同步配置；
- 上线验收 + 2 周试运行支持。

交付周期：7–14 天。

## 产品化方案（试点验证后）

- 实施费：$2000–5000（含更深度的定制：评分体系设计、CRM 对接、多渠道深链归因方案）；
- 托管服务：$200–800/月（含服务器与运维、系统升级、知识库更新协助、故障响应）。

## 说明

- AI 模型调用费用（OpenAI/DeepSeek 的 API 费用）由客户的 API Key 承担，通常每月 $5–30，取决于咨询量；
- 试点客户升级产品化方案时，试点费用可抵扣实施费；
- 托管服务按月付费，可随时取消；取消后可交付全部数据导出。

## 购买流程

1. 需求沟通（30 分钟）：了解你的产品、客户来源、现有咨询量；
2. 报价确认与付款；
3. 资料收集与配置（我们主导，你只需提供资料）；
4. 验收测试（用真实问题测试机器人回答质量）；
5. 上线，开始接客户。
