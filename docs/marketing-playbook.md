# Mercury 自营销手册（第一案例：用 Mercury 卖 Mercury）

> 定调：Mercury 的第一个客户是它自己。所有引流指向自己的 Telegram 机器人，
> 客户体验到的接待流程就是产品本身；概览页渠道表就是营销实验看板。
> 红线：不做主动群发、不抓群成员，只做价值输出（MVP 文档 §4）。
>
> 使用方式：下文所有「[机器人链接]」都从后台「推广获客」页生成——选对应触点，
> 复制带渠道码的深链或下载二维码，转化会自动归因到该渠道。
