# Nimbus AI API 产品资料（虚拟演示企业）

> 本文档为演示用虚拟产品资料，对应 MVP 文档 §10.2 的演示验收剧本。

## 产品概述

Nimbus AI API 是面向企业的大模型推理与知识问答 API 平台，提供文本生成、
向量检索、函数调用与批量推理能力。客户通过 REST API 或官方 SDK
（Python / TypeScript / Go）接入，平均首字延迟低于 800 毫秒。

## 部署方式

### 云端 SaaS

默认以多租户 SaaS 提供，数据中心位于新加坡与法兰克福，支持数据驻留选择。

### 私有化部署

Nimbus 支持完整私有化部署（on-premise / 专有云）：提供 Docker 与 Kubernetes
两种交付形态，最低资源要求为 4 张 A10 级 GPU。私有化版本包含离线 license、
本地模型仓库与升级工具，模型权重不出客户内网。私有化部署交付周期约 2–4 周。

## 集成能力

### CRM 集成

官方支持 HubSpot 与 Salesforce 集成：可以把对话摘要、线索字段自动写入
CRM 联系人时间线。HubSpot 集成通过官方 App Marketplace 安装，配置约 30 分钟。

### 协作工具

支持 Slack、Microsoft Teams 机器人接入，以及 Zapier / Make 自动化连接器。

## 定价

### 标准版

按用量计费：每百万 token 8 美元起，包含 99.9% 可用性 SLA 与工单支持。

### 团队版

面向 20–100 人团队：每席位每月 29 美元，含共享知识库、SSO 单点登录与
审计日志。50 人团队的参考年费约为 17,400 美元（按年付享 85 折）。

### 企业版与私有化

企业版与私有化部署采用定制报价，请联系销售安排评估与 Demo。

## 安全与合规

已通过 SOC 2 Type II 与 ISO 27001 认证；支持数据加密（传输 TLS 1.3、
存储 AES-256）、审计日志导出与基于角色的访问控制（RBAC）。
